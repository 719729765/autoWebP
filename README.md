如果你经常需要处理网站图片、素材图片，或者需要把大量 JPG、PNG、AVIF 图片转换成 WebP，那么这款 WebP 自动转换器可以减少重复操作。

WebP 自动转换器 v1.0 是一款基于 Python + PySide6 + Pillow + Watchdog 开发的 Windows 桌面工具。选择一个图片文件夹后，软件会在后台持续监控目录，发现新增或修改的图片后自动进行转换。

支持格式

目前支持 JPG、JPEG、PNG、BMP、GIF、TIF、TIFF、AVIF 等格式输入，并统一转换为 WebP。其中 AVIF 转 WebP 对需要整理现代图片格式的网站素材比较实用。

主要功能

自动监控：实时监控指定文件夹及子文件夹。
批量转换：启动监控后自动扫描已有图片。
AVIF 支持：AVIF 图片可直接转换为 WebP。
质量调节：WebP 图片质量支持 10～100，默认 85。
灵活输出：可保存到原目录，也可以自动创建 WebP 文件夹。
重复处理：支持跳过或覆盖已有文件。
删除原图：转换成功后可选择自动删除原图片。
后台运行：关闭窗口后可隐藏到 Windows 系统托盘。
实时统计：显示扫描、转换、跳过和失败数量，并提供运行日志。

使用方法

打开程序后选择需要监控的图片文件夹，设置 WebP 质量和输出位置，点击开始监控即可。之后将 JPG、PNG、AVIF 等图片放入该目录，程序会自动完成转换。

例如：

001.jpg → 001.webp
002.png → 002.webp
003.avif → 003.webp

程序会等待文件复制完成后再进行处理，降低图片尚未写入完成就开始转换造成失败的情况。
