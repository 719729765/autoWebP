# WebP 自动转换器

**当前版本：v1.3**

一款基于 Python + PySide6 开发的 Windows 图片自动转换工具，支持 WebP / AVIF 格式转换、图片尺寸限制、自动文件夹监控和批量手动转换。

无需逐张处理图片。选择监控目录后，程序即可自动检测新增图片并按设置完成转换。

## ✨ 功能特点

- **多格式输入**：支持 JPG、JPEG、PNG、BMP、GIF、TIFF、WebP、AVIF。
- **双格式输出**：支持 WebP 和 AVIF。
- **图片质量调节**：提供 10～100 的质量调节范围。
- **等比例缩放**：可分别设置最大宽度和最大高度，超出限制时自动等比例缩小，不会放大原图。
- **自动文件夹监控**：检测指定目录中的新增或修改图片并自动转换。
- **手动转换**：支持手动选择图片进行转换。
- **同格式尺寸优化**：同扩展名图片在尺寸超出限制时，触发等比例缩放和重新编码；尺寸未超限则跳过。
- **灵活的输出位置**：支持保存到原目录或自动创建输出文件夹。
- **重复文件处理**：支持目标文件存在时跳过或覆盖。
- **原图保护**：可以选择转换成功后删除原图，默认不删除。
- **配置记忆**：自动保存当前设置。
- **运行日志**：显示扫描、转换、跳过和失败信息。
- **系统托盘**：支持系统托盘运行。

## 📥 使用方法

### 方式一：使用 EXE

1. 前往 GitHub Releases 下载最新版本。
2. 下载 `WebP自动转换器.exe`。
3. 双击启动程序。
4. 选择需要监控的图片文件夹。
5. 设置输出格式、图片质量和最大尺寸。
6. 点击「开始监控」。

### 方式二：运行 Python 源码

需要安装 Python 环境。

安装依赖：

```bash
python -m pip install --upgrade PySide6 Pillow watchdog pillow-avif-plugin
```

运行程序：

```bash
python main.py
```

将 `ico.ico` 与 `main.py` 放在同一目录，即可使用程序图标。

## ⚙️ 参数说明

| 参数 | 说明 |
|---|---|
| 输出图片格式 | WebP / AVIF |
| 图片质量 | 10～100 |
| 最大宽度 | 0 表示不限 |
| 最大高度 | 0 表示不限 |
| 扫描间隔 | 1～60 秒 |
| 自动转换新增图片 | 开启后自动处理监控目录中的图片 |
| 转换成功后删除原图 | 默认关闭 |
| 输出位置 | 原目录 / 自动创建输出文件夹 |
| 重复文件处理 | 已存在则跳过 / 覆盖 |
| 自动记住当前设置 | 保存用户配置 |

### 同格式图片处理规则

v1.3 针对输入扩展名与输出扩展名相同的情况增加了尺寸检测：

| 图片情况 | 处理方式 |
|---|---|
| WebP → WebP，尺寸超限 | 等比例缩小并重新编码 |
| WebP → WebP，尺寸未超限 | 跳过 |
| PNG → PNG，尺寸超限 | 等比例缩小并重新编码 |
| JPG → JPG，尺寸超限 | 等比例缩小并重新编码 |
| 不同扩展名 | 按正常格式转换流程处理 |

例如：最大宽度设置为 1920px、最大高度设置为 1080px，图片只要有一个维度超限，就会按比例缩小。

**注意：同格式图片尺寸未超限时不会进行无条件二次压缩。**

## 📦 Windows EXE 打包

在项目目录打开 CMD，执行：

安装打包工具：

```bash
python -m pip install --upgrade PyInstaller
```

清理旧构建文件：

```cmd
rmdir /s /q build
rmdir /s /q dist
del /q WebP自动转换器.spec
```

执行打包：

```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed --name "WebP自动转换器" --icon "ico.ico" main.py
```

生成文件：

```text
dist/
└── WebP自动转换器.exe
```

采用 PyInstaller 自动依赖分析，不强制收集整个 PySide6 资源目录，有助于控制 EXE 体积。

打包后请实际测试 WebP、AVIF 转换和文件夹监控功能。
